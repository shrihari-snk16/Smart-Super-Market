🛒 SMARTKART ✦

A modern grocery shopping web application built using HTML, CSS, and JavaScript.

SMARTKART provides an interactive shopping experience with category-based product filtering, cart management, automatic discount calculation, multiple payment options, and a fully responsive user interface.

🚀 Live Demo

🔗 Live Website: https://your-vercel-link.vercel.app

---

✨ Features

🛍 Shopping Experience

- Browse grocery products
- Category-wise filtering
- Quantity selection
- Add-to-cart functionality
- Dynamic cart updates
- Responsive shopping interface

💰 Smart Discounts

Order Value| Discount
₹400+| 5%
₹700+| 10%
₹1000+| 15%

💳 Checkout System

- Cash Payment
- Card Payment
- UPI Payment
- Order Confirmation Screen
- Digital Receipt Generation

🎨 Modern UI

- Responsive Design
- Dark Theme Interface
- Animated Background Effects
- Toast Notifications
- Confetti Celebration Animation
- Smooth User Experience
